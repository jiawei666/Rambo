# 文件预览兼容范围（F05）

此表描述 Rambo 的聊天展示方式，不限制 Codex 实际能读取或处理的文件。音视频是否能解码还取决于当前 Electron/Chromium 构建和具体编码。

| 类型 | 应用内展示 | 识别的扩展名 | 本轮 Electron 实测 |
| --- | --- | --- | --- |
| 图片 | Grok 风格附件卡片内显示图片，点击进入共享全屏查看器；按原像素缩放至 25%–400%，双击切换 100%/200%，透明区域显示棋盘格 | `.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.avif` | 普通 PNG 与透明 PNG；附件卡片、查看器、缩放和棋盘格 |
| PDF | 附件卡片上的“预览”按钮打开共享全屏 PDF 查看器 | `.pdf` | PDF 查看器加载页面，保存副本逐字节一致 |
| 纯文本 | 附件卡片上的“预览”按钮打开共享全屏等宽文本查看器 | `.txt` | UTF-8 文本 |
| Markdown | 附件卡片上的“预览”按钮打开共享查看器并渲染 Markdown | `.md`、`.markdown` | 标题、粗体和表格 |
| CSV | 附件卡片上的“预览”按钮打开共享查看器中的可滚动表格；支持双引号包裹字段和转义引号 | `.csv` | 含中文及带逗号字段 |
| 音频 | Grok 风格附件卡片内的 HTML 音频播放器，使用流式读取和 Range 请求 | `.mp3`、`.m4a`、`.wav`、`.ogg`、`.aac`、`.flac`、`.opus` | 16-bit PCM WAV，9 MiB；成功读取元数据及字节范围 |
| 视频 | Grok 风格附件卡片内的 HTML 视频播放器，使用流式读取和 Range 请求 | `.mp4`、`.webm`、`.mov`、`.m4v`、`.ogv` | H.264 Baseline MP4 可加载元数据；无效容器显示解码错误和本机打开入口 |
| Office 与其他文件 | 统一附件卡片；保存副本、交给系统默认应用打开、Finder 定位，不提供 Office 应用内阅读器 | `.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt`、`.pptx` 及工作区内其他常规文件 | Word/Excel/PowerPoint 卡片及路径授权；RTF 交给 TextEdit，Finder 定位成功 |

## 行为边界

- 二进制资源通过受消息 ID 授权的 `rambo-asset:` 流式协议提供，不将整段音视频复制到 Renderer 内存；支持 HTTP Range，单个文件不受 8 MiB data URL 限制。
- 所有文件格式共用 Grok 风格的附件卡片；图片、PDF、纯文本、Markdown 和 CSV 的应用内预览使用同一全屏查看器外壳，Office 和未知格式保留本机打开操作。
- 文本、Markdown 和 CSV 的应用内读取上限为 2 MiB；超过后提示用户保存或用本机应用打开。
- 浏览器播放器只保证 Electron 当前构建实际支持的编码。遇到不支持的编码时显示错误，并保留本机应用打开和 Finder 定位操作。
- Office 和未知格式不在内置解析器范围内。只有目标机器安装并关联了相应应用，系统打开操作才能实际打开它；否则仍可保存文件或在 Finder 中定位。
- 资源路径必须对应助手消息，且位于该 Bot 工作区；历史图片生成结果还需与该消息对应的已完成生成活动相符。未知扩展名作为二进制文件交给系统处理，不内嵌执行。
