# WX-LIVE-CHAT-001：独立微信密钥捕获与聊天读取

## 目的

不经过 Rambo 正式“连接微信”向导、Connection 或 Bot Grant，单独验证这条本机链路：

**受管微信副本 → Frida 密钥捕获 → SQLCipher 数据库校验 → Worker 解密 → 会话与聊天消息查询 → 本机媒体解密。**

本用例里的“监听”是观察微信进程读取本机数据库时使用的密钥，不是订阅新消息或实时推送。朋友圈不在本用例和当前 Connector 范围内。

## 前置条件

- macOS，安装的腾讯官方微信为受支持的 4.1.x。
- Rambo 项目依赖已安装，并已执行 `npm run build`，确保 `out/main/wechat-worker.js` 对应当前源代码。
- 微信账号目录已由用户授权访问。首次运行需要在目录选择器中选择对应的 `wxid_*` 账号目录；后续诊断器会记住账号选择。
- 首次创建受管微信副本时，用户完成微信登录和系统管理员授权。之后尽量复用已登录副本；不要为重复诊断关闭或重启诊断器/副本。
- 准备一个已在本机缓存的聊天媒体样本，建议图片和语音各一个；视频、文件或贴纸样本可按本机已有内容补测。整个用例只打开已有消息，不发送消息。

## 启动

在仓库根目录运行：

```bash
node scripts/run-wechat-live-diagnostic.mjs
```

脚本会临时准备并启动独立 Electron 诊断器。诊断器复用 Rambo 受管微信副本，记住账号目录，但不创建正式 Rambo Connection、Bot Grant 或聊天归档。

## Computer Use 步骤

1. 查看“微信实时诊断”窗口。确认窗口说明当前为独立诊断，且提供“开始监听”和“结束监听并验证”两个按钮。
2. 若首次出现账号目录选择器，选中目标账号的 `wxid_*` 目录。若系统要求管理员授权，由用户在 macOS 系统窗口完成。
3. 如果受管微信副本需要登录，在副本内完成登录并确认会话列表已出现。登录完成后回到诊断器；不要关闭诊断器或副本。
4. 点击“开始监听”。等待日志依次显示副本复用/启动、Frida 附加、钩子就绪。捕获运行期间不要重开程序；它不会自行结束。
5. 在受管微信副本中打开至少一个私聊和一个群聊，滚动到已有消息；再打开已有图片并播放已有语音。若本机已有视频/文件/贴纸缓存样本，也打开相应消息。避免发送新消息。
6. 观察诊断器的候选密钥计数增加。计数只表示候选数量，不表示成功解密；不要因计数一时不变而重启程序。
7. 页面操作完成后，回到诊断器点击“结束监听并验证”。这是唯一正常结束本轮捕获的操作。
8. 查看安全诊断日志：候选密钥通过 SQLCipher 首页 HMAC 校验；会话库、聊天消息库和媒体库显示匹配；Worker 解密会话目录并执行聊天时间范围查询。
9. 若消息结果返回了可用媒体句柄，诊断器应读取并在内存中解密缓存样本，随后清除媒体字节。图片/语音为必查项；视频、文件和贴纸只在本机有对应缓存且查询返回句柄时判定。
10. 需要重复验证时，在同一诊断器窗口再次点击“开始监听”，继续使用同一个受管微信副本；完成后再次点击“结束监听并验证”。不要频繁退出或重启进程。

## 通过条件

- 所有当前聊天读取必需的数据库均通过 SQLCipher HMAC 校验：联系人、会话、消息分片及媒体数据库。SNS/朋友圈数据库不计入匹配数量，也不是成功条件。
- Worker 能解密会话目录，并对已选会话执行消息查询；结果页的时间范围、数量和完整性诊断与查询一致。仅有候选密钥数量或 HMAC 匹配不足以通过。
- 场景准备了本机缓存媒体时，图片和语音至少各有一个可读取样本并完成内存解密；有可用视频/文件/贴纸样本时，分别记录其结果。
- 诊断器保持打开，结束一轮后受管微信副本仍运行；可在同一窗口再次开始新一轮。
- UI/日志只呈现阶段、数据库类别、候选数和查询计数；不得显示密钥、聊天正文、联系人名称、原始媒体内容或账号目录完整路径。
- 不创建正式 Connection/Grant，不把聊天正文或媒体字节持久化到 Rambo。

## 失败记录

失败时只记录诊断器阶段、错误码、数据库类别、匹配计数、会话/消息返回数量及是否出现可用媒体句柄。不要复制密钥、数据库文件、聊天正文或包含账号目录的原始命令输出。捕获没有自动停止时，先在微信副本内完成必要页面操作，再由用户点击“结束监听并验证”；不要通过强制退出进程来复位。

## 证据边界

本用例验证独立的本机密钥捕获、数据库解密与 Worker 查询链路。它不验证正式 Connection/Grant 的持久化、Bot 动态 Tool 的授权调用、完整历史无遗漏、全部消息类型覆盖或媒体内容理解。若只返回查询首页，也不能据此声称整段时间范围已完整读取。
